This is a template short post. Write your post content here in markdown.

Posts are shorter pieces that appear in the "Short posts" section. They work the same as essays but are stored in the `_posts` folder.

## You can use headings

And all the usual markdown formatting:

- Lists
- **Bold text**
- *Italic text*
- [Links](https://example.com)

```
Code blocks work too
```

To create a new post, create a new file in `_posts` with the naming format: `YYYY-MM-DD-title.md`
